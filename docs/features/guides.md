# Guides

A library of how-to articles on planning, packing, food, gear and destinations that a user can browse, filter, search and read inside the app.

## The model in one paragraph

A guide is a short article written for hikers and campers. Each one has a title, a one-line summary, one or more topics (Food & Nutrition, Trip Planning, Family Adventures and so on), a difficulty level, an author and a reading time. Guides are published by PackRat; users read them but do not write, edit or rate them. The library is one list the user narrows by topic or by searching, and every guide opens into a full reading view.

## Getting to guides

The Dashboard has a Guides row, "How-tos for planning, packing and the trail", that opens the library. Guides also come up when the user searches the Dashboard for words like guide, help, tutorial or learn.

## Browsing the library

The Guides screen opens on every guide, newest first. A row of topic chips sits under the screen title. On Android it stays put while the list scrolls; on iPhone, iPad and Mac it scrolls away with the list, under a large title. **All** is selected to begin with; choosing a topic shows only guides in it, and the selected chip carries a checkmark. Only one topic is selected at a time.

Each guide is a card that shows, from top to bottom:

- its first topic and its difficulty, as one small line ("Food & Nutrition · Beginner")
- its title, up to two lines
- its summary, up to two lines
- the author and reading time ("By Jamie Rivera · 6 min read")

The whole card opens the guide. More guides load as the user nears the end of the list, and pulling down refreshes it.

While the first page loads, the screen shows placeholder cards in the same shape as real ones, so nothing moves when the guides arrive. If loading fails, the screen says "Couldn't load guides" with a **Try again** button. If a further page fails, the end of the list says so and offers **Try again** without disturbing what is already shown. A topic with no guides says "No Food & Nutrition guides yet" and offers **Show all guides**.

## Searching

The search button in the top bar opens a full-screen search over the library. Before the user types, it suggests searching by topic, gear or destination. Results appear as the user types, as the same cards as the library, with a count above them. Search matches titles first, then summaries, then the article text. With nothing found, it says "No results for" the query and suggests another word or browsing by topic. Going back closes search and returns to the library exactly as it was.

## Reading a guide

A guide opens full screen under a plain top bar with a back arrow. The page reads, from top to bottom:

- its topics and difficulty, as small tags
- the title, large
- the byline: author, reading time and when it was last updated
- the summary, set slightly larger as an introduction
- the article itself, with headings, lists, quotes and links in a comfortable reading size

Below the article, **Related guides** lists up to three other guides on the same topic, as compact cards that open the same way.

While a guide loads, the page shows placeholders in the shape of its title and opening lines. If it cannot load, it says "Couldn't load this guide" with a **Try again** button. Going back returns to the library at the same place and topic.

## What the user controls

- Which topic the library shows, one at a time, or all.
- What to search for.
- Refreshing the library by pulling down.

## What this feature does not do

- Save or bookmark guides, or keep a reading history.
- Share a guide as a link.
- Remember recent searches.
- Show cover images, a table of contents or reading progress.
- Let users write, rate or comment on guides.
- Sort the library any way other than newest first.
